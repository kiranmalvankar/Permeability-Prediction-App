\# Permeability Prediction Tool



A QSAR-based web application for predicting Caco-2 permeability (logPapp) from molecular SMILES.



\## Features



\- Random Forest model

\- Morgan Fingerprints (2048 bits)

\- RDKit molecular descriptors

\- Applicability Domain (k-NN based)

\- Molecular structure visualization

\- Streamlit web interface



\## Dataset



\- 12,290 molecules

\- Endpoint: Caco-2 Permeability (logPapp)



\## Validation



\- 5-Fold Cross Validation R²: 0.598 ± 0.009
